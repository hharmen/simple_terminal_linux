    - Можно написать команду с поддержкой undo, для этого нужно написать функцию undo внутри вашего питон файла с командой с входом shell (ShellCore из shell.py). Так же можете пользоваться вспомогательным стеком shellCore.stack_undo. ОБЯЗАТЕЛЬНО ЗАПИСЫВАЙТЕ ХОТЬ ЧТО-НИБУДЬ В undo_stack execute если хотите пользоваться undo
    - Очень рекомендую resolve_path метод из ShellCore чтобы получать полный путь для всех файлов и аргументов (через него и поддерживается ~)

## Алгоритм решения

- Основная оболочка это shell.py класс ShellCore
- Переменные ShellCore
    - root путь репозитории
    - pwd там где ты находишься (отоброжается в терминале)
    - trash_path путь к папке .trash где храниться мусор для undo rm
    - undo_stack для вспомогательной информации команды undo
    - history_path путь к файлу .history для истории
    - shell_log_pth путь к файлу shell.log для логгирования
    - commands список доступных комманд
- Методы ShellCore
    - \_\_init\_\_ иницализация класса ShellCore
    - setup_history создает .history при необходимости и создает переменную history_path
    - setup_logging создает переменную shell_log_path и настраивает формат логгирования
    - load_command динамически импортирует в commands все модули в папке bin
    - resolve_path обработка путей, использую везде для получения полной пути для комманд
    - parse_command парсит комманду чтобы правильно разделить все аргументы
    - exec_command выполняет саму команду из доступных в переменной commands
    - log_command логгирование команды
    - run запуск самой оболочки в интерактивном режим, для выхода нужно ввести exit

# Руководство по использованию

## Как запустить?

### ДАННАЯ ОБОЛЧКА РЕКОМЕНДУЕТСЯ ЗАПУСТИТЬ ТОЛЬКО НА LINUX, ТАК КАК НА ДРУГИХ ОС ОН НЕ ТЕСТИРОВАЛСЯ (был написан и тестирован на debian 13 с ядром Linux 6.12.57+deb13-amd64)

Необходимо перейти в корневую директорию репозитория и написать команду
<pre> python3 -m src.main </pre>
После этого запуститься сама оболчка в интерактивном режиме (впринципе только в таком и поддерживается он) и будет находится в директории откуда запустили (то есть там где находится репозиторий)

### Не рекомендуется каким-либо способом трогать папку репозитория (если и так все работает) иначе все может сломаться

## Доступные команды

### cat

Выводит в консоль содержимое файла (тут особо рассказывать нечего)

#### cat \<path to file>

### cd

Меняет текущую директорию на ту, которую введете

#### cd \<path>


### ls

Выводит содержимое директории путь котроого укажите. Если ничего не ввести, то укажет содержимое текущей директории. Доступен флаг -l который показывает подробную информацию о каждом элементе внутри директории

#### ls [-l] \<path to dir>


### rm

Удаляет файл, который укажите. При попытке удалить директорий требуется флаг -r и подтверждение вводом y

rm [-r] <path to file/dir>

### cp

Копирует файл или директорию туда, куда введете. Можно копировать файл в директорию, можно копировать файл внутрь другого файла или создать новый файл куда будет скопирован изначальный. Можно копировать директории если вести флаг -r, директории нельзя копировать поменяв имя, можно только копировать в другую директорию, при условии, что путь копирования не лежит внутри директории которую хотите скопировать.

#### cp [-r] <path to file/dir> <path to file/dir>

### mv

Может перемещать файл/директорию в указанную директорию (но если ввесть такую путь, которая не существует, то файл/директория будет переименована)

#### mv <path to file/dir> <path to file/dir>"

### grep

Поиск файлов по содержимому. Выводит список файлов с номерами строк, в которых встретились строки удовлетворяющие регулярному выражению, который введете. Доступен флаг -r для рекурсивного поиска в подкаталогах. Доступен флаг -i для поиска без учёта регистра

#### grep [-r] [-i] <pattern> <path to file/dir>

### history

Выводит историю команд. Сохраняется даже после перезагрузки оболочки.

#### history

### undo

Отменяет последнюю команду из cp mv rm. ВНИМАНИЕ ОТМЕНЯЕТ ТОЛЬКО ПОСЛЕДНЮЮ, ЕСЛИ ВВЕСТИ ДРУГУЮ КОМАНДУ ТО UNDO СКАЖЕТ НЕЛЬЗЯ

#### undo

### zip

Архивирует директорию в zip файл. Если пытаться вести название архива, которую хотите создать, без .zip, то автоматически добавляется в конце .zip. Если название архива занято, то добавиться номер в конце в скобках (минимальное натуральное число, при котором не занято название архива)

#### zip <path to file> <archive.zip>

### unzip

Разархивирует zip архив. Если название директории занято для разархивирования, то добавиться номер в конце в скобках (минимальное натуральное число, при котором не занято название)

#### unzip <archive.zip>

### tar

Архивирует директорию в tar.gz файл. Если пытаться вести название архива, которую хотите создать, без .tar.gz, то автоматически добавляется в конце .tar.gz. Если название архива занято, то добавиться номер в конце в скобках (минимальное натуральное число, при котором не занято название архива)

#### tar <path to file> <archive.tar.gz>

### untar

Разархивирует tar.gz архив. Если название директории занято для разархивирования, то добавиться номер в конце в скобках (минимальное натуральное число, при котором не занято название)

#### untar <archive.tar.gz>

### exit

Выходит из оболочки

#### exit
